Paysage des modèles de décision

Sept familles de solutions transforment un texte en décision typée, propriétaires et ouvertes. Cette page les recense produit par produit, avec licence, déploiement, sortie, probabilités, prix et source : 39 entrées, chacune liée à sa source, relevées le 1er octobre 2026.

01 · En bref

Seuls les modèles de décision, hébergés ou ouverts, combinent un format garanti, une probabilité par option et une seule passe par question. Les LLM avec structured outputs garantissent le format mais pas les probabilités ; les encodeurs zero-shot donnent des probabilités, sur CPU, mais sans calibration annoncée.

Les chiffres de performance publiés par chacun viennent de jeux différents : ils ne se comparent pas entre eux. Nos comparaisons à périmètre égal sont sur la page Résultats.

09 · Méthode et données

Chaque ligne renvoie, depuis son nom, à la page dont elle vient : celle de l'éditeur ou son dépôt, relevée le 1er octobre 2026. Les affirmations des éditeurs (calibration, vitesse) sont rapportées comme telles. Une case vide signifie que l'information n'était pas sur la page.

Les données sont téléchargeables : landscape.csv (en anglais). D'autres projets cités par des annuaires tiers (Kev, Von, NanoJev, SemIf, djev…) entreront ici quand on aura pu les vérifier sur leurs propres pages. Une erreur ou un oubli : ouvrez une issue.
